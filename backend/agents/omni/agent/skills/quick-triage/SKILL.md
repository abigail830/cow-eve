# Quick triage

1. Restate the user's goal in one sentence.
2. Decide routing:
   - **Self-serve (haoyu-omni)**: light Q&A, summaries, knowledge lookup via `kb-qa`.
   - **Documents / decks**: activate `docx`, `pptx`, or `html-slides` on haoyu-omni (see content-studio instructions).
   - **Schedules**: recurring or one-time automated runs via schedule tools.
3. If self-serve: answer directly and briefly.
4. If documents/decks: activate the format skill and follow content-studio workflow (`publish` when done).
5. Summarize the outcome for the user.
