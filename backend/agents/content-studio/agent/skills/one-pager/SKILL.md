# One-pager outline

Produce a 16:9 one-page structure with:

| Area | Content |
|------|---------|
| Kicker | Short eyebrow |
| Title | One clear headline |
| Subtitle | Supporting line |
| Left card | Key points |
| Right card | Evidence / next steps |

Call out brand constraints if the user named any. Keep copy tight.
